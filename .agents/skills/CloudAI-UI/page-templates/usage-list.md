# UsageList 用量列表

**何时选它**：用户要弄清**一个量**是怎么花掉的——上方是这个量的**总量与趋势**，下方是构成它的
**明细流水**。判据的两头缺一不可：只有表格没有概览的，不是这一页。表里一行是一条只读记录，不是一个
能改名删除的对象。

**试用场景**：Credit 用量、Token 消耗、调用量明细、存储配额、任务执行流水。

**表里一行点开是某个对象的详情页**时不是这一页，回 `SKILL.md` 的选型表重选。

**先抄 [AppShell](app-shell.md)**，本模板只是它 `SLOT:PageContent` 里的内容子树，不含顶栏与侧栏。

**抄 [`usage-list.tsx`](page-templates/usage-list/usage-list.tsx)，看 [`usage-list.reference.tsx`](page-templates/usage-list/usage-list.reference.tsx)。**
把骨架复制进你的页面，按还原件填 `SLOT:`。**不要 `import`，也不要整页抄还原件。**

下面这些是契约，照抄，不要凭手感重算。

## 结构

```txt
模板根（min-h-full flex-col）
├── Breadcrumb（sticky top-0，不透明底 + 底部渐变遮罩）
└── 正文（上 16 下 36，左右 36，块间 24）
    ├── 概览组
    │   ├── PageHeading     标题 + 可选副标题 + 右侧操作区
    │   └── SummaryCard     一张卡，内部 2～N 栏，栏间 32
    └── 表格区（块间 16）
        ├── SectionLabel
        ├── SearchFilterToolbar   ┐
        ├── UsageTable            ├─ 这三块是同一个 DataTablePro
        │   └── UsageRow          │
        └── Pagination            ┘
```

## 高度：一行都不要写

**表格多高由行数决定，分页紧跟在它下面，页面底部允许留白。** 这就是 `DataTablePro` 的默认行为，
所以关于高度**你什么都不用传**——不传 `h-full`、不传 `flex-1`、不在 `scrollContainerClassName` 上写
`max-h-[560px]`。

两个方向都是错的，而且错法很像「更完整」：

| 错法                          | 后果                                                               |
| ----------------------------- | ------------------------------------------------------------------ |
| 撑满高度把分页钉在视口底      | 行少于一屏时，表格与分页之间拉出一大片空白，内容中间被断开         |
| 给表格写死 `max-h` 让表体内滚 | 宽屏下表格底部留白；矮屏下分页被顶出视口；滚轮落在哪取决于指针位置 |

底部留一块白比上面两种都好看，也比它们好用。**这条是 DEC-105 定的**，不是省事。

**连带结果：表头不 sticky。** `sticky` 认的是最近的滚动祖先，也就是 `DataTable` 自己那个
`overflow-auto` 容器（它为横向滚动一直存在）；该容器高度随内容之后，`sticky top-0` 就没有可吸附的
余量。想要表头常驻只能回到「撑满 + 表体内滚」，而那一套已经被否掉了。

## 每个槽都有现成组件，一个都别手搓

| 槽                                                  | 用这个组件                                         | 备注                                                         |
| --------------------------------------------------- | -------------------------------------------------- | ------------------------------------------------------------ |
| `Breadcrumb`                                        | shadcn `Breadcrumb`                                | `npx shadcn@3 add breadcrumb`；末级用 `BreadcrumbPage`       |
| `SearchFilterToolbar` + `UsageTable` + `Pagination` | `DataTablePro`                                     | **一个组件盖三槽**，见下                                     |
| 筛选                                                | `FilterGroupV2`（传给 `DataTablePro` 的 `filter`） | pill、多选、日期、「+」加筛选项都由它管                      |
| 搜索                                                | `Input`，`className="h-8 w-56"`                    | 与工具栏其它控件对齐                                         |
| 结果标签                                            | `StatusBadge`                                      | 异常 `warning-high` / 风险 `warning-medium` / 正常 `success` |
| 概览区进度                                          | `ProgressPro`                                      | —                                                            |
| 概览区趋势图                                        | `ChartPro`                                         | 示意，不规定图表库与柱子数量                                 |

**那三槽是同一个组件。** `DataTablePro` 的根布局就是 `flex flex-col gap-4`：工具栏（`search` /
`filter` / `onRefresh` 三个插槽）→ 表格 → 分页右对齐（`pagination` prop）。稿面那三块的排布与 16 的
间距、分页右对齐，与它逐项吻合，所以不要自己再排一遍。

```tsx
<DataTablePro
  columns={columns}
  data={rows}
  showColumnSettings={false}
  search={<Input placeholder="搜索..." className="h-8 w-56" />}
  filter={
    <FilterGroupV2
      allFilters={allFilters}
      showKeys={showKeys}
      onShowKeysChange={setShowKeys}
      filters={filters}
      onChange={setFilters}
    />
  }
  onRefresh={reload} // 重新拉数据，怎么拉归你
  pagination={{ variant: 'normal', total, current: page, onChange: setPage }}
/>
```

**三色标签走语义 token，不要自己配颜色，也不要加第四种。**

## 不可变量

| 量                | 值                                                   |
| ----------------- | ---------------------------------------------------- |
| 内容左右内边距    | 36（`px-9`），型 ② 全宽数据型                        |
| 面包屑行          | 上 20（`pt-5`），`sticky top-0`，底部 16 的渐变遮罩  |
| 正文上下          | 上 16（`pt-4`）、下 36（`pb-9`）                     |
| 概览组 ↔ 表格区   | 24（`gap-6`）；`PageHeading` ↔ `SummaryCard` 同为 24 |
| 表格区内部各块    | 16（`gap-4`），与 `DataTablePro` 自带的 `gap-4` 同值 |
| `SummaryCard`     | 内边距 16，圆角 16，中性描边；栏间 32（`gap-8`）     |
| `UsageTable` 外框 | 圆角 8，中性描边                                     |
| 表头高            | 36（`h-9`）                                          |
| 行高              | 52（`h-[3.25rem]`）                                  |
| 工具栏高          | 40（`h-10`）                                         |

**这张表里没有任何高度上限**，这是故意的，见上面「高度：一行都不要写」。

**正文撑满内容区，不限宽也不居中。** 这点和概览页、对话页相反——那两页是聚焦阅读型、内容列恒 800；
这页是全宽数据型，宽度就是拿来放列的。超宽档下表格跟着内容区一起拉宽。

## 插槽

| 插槽                  | 允许放                                   | 禁止放                          | 空态                       |
| --------------------- | ---------------------------------------- | ------------------------------- | -------------------------- |
| `Breadcrumb`          | 多级面包屑导航，单行                     | 搜索框、操作按钮                | 顶层页面时整行不渲染       |
| `PageHeading`         | 标题 + 可选副标题 + 右侧操作区           | 多段正文                        | 不允许为空                 |
| `SummaryCard`         | 一张卡，内部 2～N 栏：指标、进度、趋势图 | 操作按钮、筛选、明细表格        | 无概览数据时整块不渲染     |
| `SectionLabel`        | 分组标题，单行                           | 多级面包屑、操作按钮            | 不分组时整行不渲染         |
| `SearchFilterToolbar` | 搜索输入框 + 筛选下拉，右侧可放刷新      | 行内展开的高级筛选面板          | 不允许为空                 |
| `UsageTable`          | 表头 + N 行 `UsageRow`                   | 内联编辑、展开行、纵向内滚      | 表体内居中提示，见「状态」 |
| `UsageRow`            | 业务自定列 + 状态标签                    | 超过一行的单元格内容            | 不允许为空                 |
| `Pagination`          | 页码 + 前后翻页                          | 批量操作（那是 `batchActions`） | 空态时隐藏                 |

## 状态

四态都是 `DataTablePro` 自带的，页面只负责接线，不另造一套：

| 状态        | 表现                                                   | 怎么接                        |
| ----------- | ------------------------------------------------------ | ----------------------------- |
| 空          | 表体内居中「暂无记录」，概览与工具栏照常，**分页隐藏** | `emptyState`                  |
| 首次加载    | 表格骨架，**表头保留**                                 | `loading`                     |
| 筛选 / 翻页 | 半透明蒙层 + loading，**保留旧数据**不闪空             | `refreshLoading`，别清空 data |
| 错误        | 表体内联报错 + 重试                                    | `emptyState` 放错误态节点     |
| 概览区加载  | 数值位骨架                                             | 概览区自己管                  |

**空态发生在表体内部，不是整页。** 整页级的空白页会把用户已经选好的筛选条件一起抹掉，他就没法回退。

**刷新时不要清空 `data`。** 清了高度会先塌再弹，视觉上比慢一点更难受。

## 响应式

| 区域   | Compact ≤1280            | Standard 1440 | Wide ≥1920           |
| ------ | ------------------------ | ------------- | -------------------- |
| 内容区 | 全宽 − 左右 36           | 1160，左右 36 | 跟随外壳撑满，不限宽 |
| 概览卡 | 栏横向压缩，必要时换行   | 横排两栏      | 跟随内容区拉宽       |
| 表格   | 列宽按比例压缩，可横向滚 | 全宽铺满      | 跟随内容区拉宽       |
| 分页   | 紧跟表格                 | 紧跟表格      | 紧跟表格             |

**纵向归属三档不变**，变的只有宽度。侧栏自动收起阈值 1440，由外壳负责。

## 滚动归属

| 层            | 行为                                                    |
| ------------- | ------------------------------------------------------- |
| 整页          | 不滚                                                    |
| `ContentArea` | **唯一的主滚动容器**（在 `AppShell` 里，本模板不再挂）  |
| `Breadcrumb`  | `sticky top-0`，不跟随滚动                              |
| 概览组        | 跟着 `ContentArea` 滚                                   |
| 表格          | 跟着 `ContentArea` 滚，**不纵向内滚**（横向溢出时才滚） |
| `Pagination`  | 紧跟表格一起滚，不钉在视口底                            |

**内容里不许再开纵向滚动容器。** 和其它内容模板同一条规矩——列表页不例外。表格自己内滚会带来两条
滚动条，用户的滚轮落在哪里取决于指针位置。

**面包屑要不透明底色。** 它 `sticky` 在滚动内容之上，底色透明的话表格会从下面透出来。

## 增强项

- **高度一行都不写。** 表格随行数、分页紧跟其后、底部允许留白。不撑满，也不写死 `max-h`。
- **分页紧跟表格**，不钉在视口底部。
- **概览区是只读指标**，不放操作按钮和筛选。要操作的场景说明你选错模板了。
- **趋势图只是示意**，不规定图表库与柱子数量。
- **结果标签三色是语义色**，业务不要自造第四种。
- 稿上的巡检样本（实例ID / 链路名称 / 巡检项 / 结果 / 建议）与 Credit 数值都是占位内容，换掉；
  列数与列宽由业务定，行高 52 留下。
