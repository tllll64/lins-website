# AgentConversation Agent 对话页

**何时选它**：用户已经和 Agent 开始对话，这一屏要显示**来回的消息流**——用户提问、Agent 回复、
回复里夹着思考过程、工具调用、执行计划与产出文件，底部常驻一个追问输入框。

**先抄 [AppShell](app-shell.md)**，本模板只是它 `SLOT:PageContent` 里的内容子树，不含顶栏与侧栏。

**抄 [`agent-conversation.tsx`](page-templates/agent-conversation/agent-conversation.tsx)，看 [`agent-conversation.reference.tsx`](page-templates/agent-conversation/agent-conversation.reference.tsx)。**
把骨架复制进你的页面，按还原件填 `SLOT:`。**不要 `import`，也不要整页抄还原件。**

下面这些是契约，照抄，不要凭手感重算。

## 结构

```txt
模板根（min-h-full flex-col，内边距 20）
└── 对话列（w-full max-w-[50rem] 水平居中，顶对齐）
    ├── 对话流（flex-1，块与块之间 32）
    │   ├── UserMessage        右对齐，宽度跟随内容
    │   ├── AgentReplyBlock    通栏无气泡，块内各段 12
    │   │   ├── AgentLogo
    │   │   ├── APICallIndicator
    │   │   ├── ContentSegment
    │   │   ├── PlanCard / ResultAttachment   上限 640
    │   │   ├── ActionBar
    │   │   └── SuggestedQuestions
    │   └── …（N 轮，纵向堆叠）
    └── ChatboxInput（sticky bottom-5，离底 20）
```

## 消息怎么摆

**两侧不是同一种排法**，这是本模板最先要抄对的东西：

| 侧         | 排法                                                              | 为什么                                                       |
| ---------- | ----------------------------------------------------------------- | ------------------------------------------------------------ |
| 用户       | `self-end` 右对齐，宽度跟随内容，上限 800（`max-w-full`），带气泡 | 短提问不该被拉成通栏，否则看不出是谁在说话                   |
| Agent      | 通栏占满对话列，**不做气泡**                                      | 回复里有计划卡、表格、附件，套进气泡就得在气泡里再套一层限宽 |
| 结果类卡片 | 上限 640，比对话列窄 160                                          | 叙述通栏、产出物收窄，扫读时一眼分得清哪些是话、哪些是交付物 |
| 追问输入框 | 跟随对话列 800，不跟随内容区                                      | 内容区在超宽档会拉到 1640，输入框跟着拉就离对话文字很远      |

## 复杂过程用现成组件，不要手搓

对话流里的过程件**全部已经封装好**。手写一遍拿不到收起动画、状态色、无障碍属性，而且状态枚举会
和组件漂开。逐槽对照：

| 槽                 | 用这个组件                                                        | 该组件自己的状态                                                      |
| ------------------ | ----------------------------------------------------------------- | --------------------------------------------------------------------- |
| `APICallIndicator` | `AiThinking`（思考）、`AiToolCall`（工具调用）                    | `running` / `success`；`AiToolCall` 另有 `error`                      |
| 多步链路           | `AiChain` + `AiChainNode` / `AiChainTaskBar`                      | 节点 `success` / `running` / `pending` / `error`，任务条另有 `paused` |
| `PlanCard`         | `AiPlanCard` + `Header` / `Content` / `Step`；确认条 `ConfirmBar` | `generating` / `pending` / `confirmed`                                |
| `ResultAttachment` | `AiAttachmentCard fluid`（`fluid` 就是消息流里的结果文件形态）    | `ready` / `uploading` / `error`                                       |
| `ContentSegment`   | 代码块 `CodeBlock`，表格 `DataTablePro`，图表 `ChartPro`          | —                                                                     |
| `ChatboxInput`     | `AiPromptInput collapsible`                                       | `idle` / `running`；`HelperText` 有 `info` / `error`                  |

**`ChatboxInput` 不要自己搭那条胶囊。** `AiPromptInput` 传 `collapsible` 后，未聚焦且内容为空时就是
稿上那条 52 高的单行胶囊（功能按钮 · 占位文案 · 发送钮），聚焦或有内容时自己形变回多行。骨架里那个
占位块的几何（内边距 12、间距 4、圆角 26）照的就是它的收起态。

**圆角写 26，不要写 `rounded-full`。** 52 高时两者一样，但形变成多行之后 `rounded-full` 会变成橄榄球。

`ActionBar` 与 `SuggestedQuestions` 没有对应组件，按骨架里的最简实现写。

## 不可变量

| 量                                       | 值                                                             |
| ---------------------------------------- | -------------------------------------------------------------- |
| 对话列宽                                 | 800（`max-w-[50rem]`），水平居中，**不随内容区拉宽**           |
| 模板根内边距                             | 20（`p-5`）                                                    |
| 块与块（用户 ↔ 回复、轮与轮）            | 32（`gap-8`）                                                  |
| `AgentReplyBlock` 块内各段               | 12（`gap-3`）                                                  |
| `AgentReplyBlock` 最小高                 | 80（`min-h-20`）                                               |
| `AgentLogo` 头像                         | 28（`size-7`），圆角 6，到名称 12                              |
| `UserMessage` 气泡                       | 内边距 16 / 12（`px-4 py-3`），圆角 14（`rounded-[0.875rem]`） |
| `PlanCard` / `ResultAttachment` 宽度上限 | 640（`max-w-[40rem]`）；`PlanCard` 最小高 304                  |
| `ActionBar`                              | 固定高 40（`h-10`），图标 24，间距 4                           |
| `SuggestedQuestions`                     | 纵向堆叠，间距 8，胶囊高 28、圆角 16                           |
| `ChatboxInput`                           | 最小高 52（`min-h-[3.25rem]`），内边距 12，圆角 26，离底 20    |

**离底那 20 与模板根的 `p-5` 是同一个数。** 输入框写 `sticky bottom-5`：浮起时离滚动视口底 20，滚到
底时停在对话列末尾也正好离底 20，所以不跳。改根内边距就要同步改这个 `bottom-`。

## 插槽

| 插槽                 | 允许放                                            | 禁止放                          | 空态                     |
| -------------------- | ------------------------------------------------- | ------------------------------- | ------------------------ |
| `UserMessage`        | 用户消息气泡 + 时间戳 + 编辑／确认操作            | 通栏排版、Agent 侧内容          | 不允许为空               |
| `AgentReplyBlock`    | `AgentLogo` + N 个内容段（文本／API／计划／表格） | 用户侧内容、跨 Agent 的混合回复 | 不允许为空               |
| `AgentLogo`          | Agent 头像（28）+ 名称文本单行                    | 多行文本、Badge                 | 不允许为空               |
| `APICallIndicator`   | 图标 + 动作标签 + 方法名，行内一行                | API 返回体全文                  | 该轮没有调用时整行不渲染 |
| `ContentSegment`     | Markdown 文本块、代码块、表格、图表               | 嵌套表格超过 2 层               | 不允许为空               |
| `PlanCard`           | 步骤列表（图标 + 步骤文本）+ 进度指示             | 与步骤无关的通用卡片            | 该轮没有计划时不渲染     |
| `ResultAttachment`   | 文件类型图标 + 标题 + 大小 + 时间                 | 内联预览                        | 该轮没有产出时不渲染     |
| `ActionBar`          | 复制／点赞／点踩／刷新，最多 4 个                 | 文本按钮、下拉菜单直接展开      | 流式产出期间不渲染       |
| `SuggestedQuestions` | 2～3 个胶囊标签，点击即发送                       | 超过 3 个、多行文本             | 无推荐问题时整块不渲染   |
| `ChatboxInput`       | 输入框 + 操作栏（附件／模式／发送）               | 第二个滚动容器                  | 不允许为空               |

## 状态

**这页的状态真源是组件，不是页面。** 每个槽的进行中／完成／失败由上面那张选型表里各组件的
`status` 承担，页面不复述一遍——写两遍就会和组件漂开。页面层只有一条：

| 状态         | 机制                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 末轮流式产出 | `ActionBar` 与 `SuggestedQuestions` 尚未挂载；已完成的前几轮不受影响 |

没产完的回复既不能复制，也谈不上追问，所以这两块是跟着流式结束一起出现的，不是一直占位再变灰。

## 响应式

| 区域       | ＜1440     | ≥1440      | ≥1920                          |
| ---------- | ---------- | ---------- | ------------------------------ |
| 对话列     | 800 居中   | 800 居中   | 800 居中，**不跟随内容区拉宽** |
| 结果类卡片 | 上限 640   | 上限 640   | 上限 640                       |
| 输入框     | 跟随对话列 | 跟随对话列 | 跟随对话列                     |

**本模板没有断点。** 对话列恒 800，而最窄目标宽 1280 下内容区还有 1256，所以稿上「Compact 时对话流
从 800 缩成 `100% − 48`」在目标范围内根本不触发。但仍然要用 `w-full max-w-[50rem]` 写对，将来最窄
下探时自动降级。

降级是**容器**驱动的（对话列可用宽），不是 viewport 驱动的——验证它只需要把容器压窄。

## 滚动归属

| 层              | 行为                                                   |
| --------------- | ------------------------------------------------------ |
| 整页            | 不滚                                                   |
| `ContentArea`   | **唯一的主滚动容器**（在 `AppShell` 里，本模板不再挂） |
| 对话流          | 跟着 `ContentArea` 滚；顶对齐、新消息追加在底部        |
| 结果卡片 / 表格 | 跟着对话流滚，**不独立滚动**                           |
| `ChatboxInput`  | `sticky bottom-5`：滚动时浮在对话流上方，滚到底时归位  |

**不要在对话流上挂 `overflow-auto`。** 这是这页最常见的写法错误：对话流自己内滚 + 输入框 `fixed`。
后果是内外两条滚动条、结果卡片在自己的小框里内滚、侧栏开合与超宽档下输入框错位。唯一的滚动容器已经
在外壳的 `ContentArea` 上了，这里只需要 `sticky`。

**输入框要 `z-10`。** 外壳在 `ContentArea` 底部盖了一层 88 高的渐变遮罩做内滚提示，输入框正好落在
遮罩范围里，不压上去就会被洗成半透明。

## 增强项

- **消息布局的不对称是刻意的**，别为了「整齐」把两侧统一：用户右对齐带气泡、Agent 通栏无气泡。
- **过程件一律用现成组件**，理由与清单见上面那张选型表。自己手写一版计划列表或附件卡，拿不到收起
  动画与状态色，而且状态枚举会和组件漂开。
- **结果类卡片收窄到 640 是信息层级，不是省地方。** 不要因为内容区在超宽档变宽就让它撑满。
- **自动滚到底写在滚动容器上。** 新消息追加后要把 `ContentArea` 的滚动容器滚到底；**不要**为了实现
  自动滚底而在对话流上新开一个滚动容器——那会连带破坏吸底与结果卡片的滚动归属。
- **一轮回复的段序不固定。** `APICallIndicator`、`ContentSegment`、`PlanCard`、`ResultAttachment` 是
  按 Agent 实际产出顺序交替出现的，可以有多个、也可以没有。骨架里各出现一次只是示意，不是顺序契约。
- 稿上的「Data Agent」「CPU 异常诊断报告」是占位内容，换掉；层级与间距留下。
- 对话进行之前那一屏是另一个模板：[Agent chat 首页](agent-chat-home.md) 的欢迎语 + 输入框居中布局。
  **不要把两者揉成一页**——那边是单屏居中，这边是顺序滚动加吸底，两套不同的布局代码。
