# AgentChatHome Agent chat 首页

**何时选它**：用户需要与 AI Agent 进行对话交互——新建对话、续接历史会话、查看 Agent 回复。
本模板画的是**进入时还没有对话**的那一屏：欢迎语、输入框、演示案例。

**先抄 [AppShell](app-shell.md)**，本模板只是它 `SLOT:PageContent` 里的内容子树，不含顶栏与侧栏。

**抄 [`agent-chat-home.tsx`](page-templates/agent-chat-home/agent-chat-home.tsx)，看 [`agent-chat-home.reference.tsx`](page-templates/agent-chat-home/agent-chat-home.reference.tsx)。**
把骨架复制进你的页面，按还原件填 `SLOT:`。**不要 `import`，也不要整页抄还原件。**

下面这些是契约，照抄，不要凭手感重算。

## 结构

```txt
模板根（min-h-full flex-col，内边距 20）
└── 内容列（w-full max-w-[42.5rem] 水平居中 + my-auto 垂直居中，段间距 96）
    ├── 欢迎语与输入框一组（间距 24）
    │   ├── WelcomeGreeting（min-h 36，左右外距 16）
    │   └── 输入框容器（rounded-2xl，px-1 pb-1）
    │       ├── QuickActionButtons（h 44，按钮各高 28）
    │       └── ChatInput（min-h 160，内边距 16；内部上输入区、下操作行 28）
    └── DemoSection（无演示案例时整段不渲染）
        ├── DemoSectionLabel（min-h 14）
        └── DemoCaseCard × N（卡片式横排，或列表式整行）
```

## 不可变量

| 量                        | 值                                                        |
| ------------------------- | --------------------------------------------------------- |
| 内容列宽                  | 680（`max-w-[42.5rem]`），水平居中，**不随内容区拉宽**    |
| 模板根内边距              | 20（`p-5`）                                               |
| 欢迎语 ↔ 输入框容器       | 24（`gap-6`）                                             |
| 输入框容器 ↔ DemoSection  | 96（`gap-24`）                                            |
| `QuickActionButtons` 条高 | 44（`h-11`），单个按钮 28（`h-7`），间距 8                |
| `ChatInput` 高            | 最小 160（`min-h-40`），内边距 16（`p-4`），底部操作行 28 |
| 段标题 ↔ 卡片             | 16（`gap-4`）                                             |
| 演示卡（卡片式）          | 高 120（`h-[7.5rem]`），间距 12（`gap-3`），圆角 16       |
| 演示卡（列表式）          | 行高 36（`h-9`），间距 8（`gap-2`），圆角 16              |

**欢迎语到输入框那 68 不要写死**：它是「间距 24 + 快捷条 44」的和。`QuickActionButtons` 在输入框
容器内、输入框上方，不是内容列的第三个兄弟——写成兄弟就得手算 68，改一次快捷条高度就错。

**演示卡宽 216 也不写死**，它是 `basis-[13.5rem] flex-1` 在 680 列里的推导值
（`3 × 216 + 2 × 12 = 672`，加两侧 `px-1` 正好 680）。写成 `w-[13.5rem]` 会失去换行能力，
写成纯 `flex-1` 则永远不换行。

## 插槽

| 插槽                 | 允许放                         | 禁止放                 | 空态                       |
| -------------------- | ------------------------------ | ---------------------- | -------------------------- |
| `WelcomeGreeting`    | 纯文本（产品名 + 欢迎语）      | 图片、按钮、多段落     | 不允许为空                 |
| `QuickActionButtons` | 2～4 个功能按钮 + 1 个扩展按钮 | 输入控件、下拉直接展开 | 整条隐藏，输入框上移       |
| `ChatInput`          | 多行文本输入 + 底部操作栏      | 第二个滚动容器         | 不允许为空                 |
| `DemoSectionLabel`   | 段标题单行（如「演示案例」）   | 多级面包屑、链接组     | 随 `DemoSection` 一起隐藏  |
| `DemoCaseCard`       | 标题 + 一句话描述              | 长段落、超过一屏的图   | 见下方状态表「无演示案例」 |

## 状态

| 状态         | 机制                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------- |
| 卡片式演示   | 3 张横排，各 `basis-[13.5rem] flex-1`                                                               |
| 列表式演示   | 整行占满内容列，行数不固定。与卡片式是同一 `DemoSection` 的两种填法，不是页面状态；容器间距各自见表 |
| 演示卡 hover | 仅 fine pointer：显示品牌描边与点阵渐变底；默认态保持普通描边与 `bg-card`                           |
| 无演示案例   | 整个 `DemoSection` 连段标题一起不渲染；剩下的内容按垂直居中规则重新居中                             |
| 首屏加载     | 各插槽的 `min-h` 就是加载态的形状：占位与实际内容同高，布局不跳。骨架的具体样式归业务               |

## 响应式

| 区域   | ＜1440   | ≥1440    | ≥1920                          |
| ------ | -------- | -------- | ------------------------------ |
| 内容列 | 680 居中 | 680 居中 | 680 居中，**不跟随内容区拉宽** |
| 演示卡 | 3 张横排 | 3 张横排 | 3 张横排，卡宽与间距不变       |

**本模板没有断点。** 内容列恒 680，而最窄目标宽 1280 下内容区还有 1256，所以「放不下时 2 + 1」在
目标范围内根本不触发。但仍然要用 `flex-wrap` + `basis` 写对，将来最窄下探时行为自动正确。

换行是**容器**驱动的（内容列宽），不是 viewport 驱动的——验证它只需要把容器压窄，不需要改 viewport。

## 增强项

- 欢迎语用**用户的语言**生成，不要写死中文或英文。稿上的英文只是举例。
- 演示卡里的具体案例是举例不是规范；卡片式固定 3 张，列表式行数不固定。
- 内容整体垂直居中于内容区，用 `min-h-full` + `my-auto`。**不要写 `h-full` + `justify-center`**：
  内容比容器高时那样会裁掉顶部，而且滚不回去；`my-auto` 有余量时居中、没余量时自动归零。
  居中是因为这是**单屏页**：一屏放得下、以「打字」这一个动作为中心。阅读流页（如
  [概览页](overview.md)）是顶对齐顺序滚动的，两者不要抄混。
- **内容列宽按页面类型选**：本页 680、概览页与对话页 800，这是刻意区分的。对话输入场景用窄列聚焦
  打字区、减少视线跳动；阅读浏览场景用宽列，适合图文并排和信息扫读。新页面照这个判据挑，不要统一
  成一个值。
- 本模板只画「还没有对话」这一屏。**对话进行中是另一个模板**：[对话页](agent-conversation.md) 那边
  输入框吸底、对话流在上方顺序滚动。不要把这一屏改造成对话页，直接抄那份。
