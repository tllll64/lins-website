# Overview 概览页

**何时选它**：用户需要了解 Agent 整体能力概览——功能介绍、核心卖点、快速上手入口。

**先抄 [AppShell](app-shell.md)**，本模板只是它 `PageContent` 插槽里的内容子树，不含顶栏与侧栏。

**抄 [`overview.tsx`](page-templates/overview/overview.tsx)，看 [`overview.reference.tsx`](page-templates/overview/overview.reference.tsx)。**
把骨架复制进你的页面，按还原件填 `SLOT:`。**不要 `import`，也不要整页抄还原件。**

下面这些是契约，照抄，不要凭手感重算。

## 结构

```txt
模板根（flex-col，内边距 20）
└── 内容列（w-full max-w-[50rem] 居中，顶对齐，段间距 48）
    ├── HeroSection（间距 32）
    │   ├── AgentBadge（min-h 38，左对齐）
    │   └── HeroBanner（min-h 160，rounded-2xl，overflow-hidden）
    │       ├── 左：HeroTitle（上）+ HeroActions（下，justify-between 撑开）
    │       └── 右：HeroPanelPreview
    └── FeaturesSection（无功能时整段不渲染，间距 16）
        ├── SectionLabel（min-h 20）
        └── FeatureCards（flex-col，xl: 起两栏，间距 32）
            ├── 左栏手风琴（xl:w-[18.125rem]，节奏 20）：标题 + 展开项 FeatureItem + 分割线
            └── 右栏 FeaturePreview（flex-1，min-h 316）
```

## 不可变量

| 量                    | 值                                                               |
| --------------------- | ---------------------------------------------------------------- |
| 内容列宽              | 800（`max-w-[50rem]`），居中，**不随内容区拉宽**                 |
| 模板根内边距          | 20（`p-5`）                                                      |
| Hero ↔ Features       | 48（`gap-12`）                                                   |
| `AgentBadge` ↔ Hero   | 32（`gap-8`）；`AgentBadge` 最小高 38                            |
| `HeroBanner`          | 最小高 160（`min-h-40`），内边距 32 / 24（`px-8 py-6`），圆角 16 |
| `HeroActions`         | 恰好 2 个 CTA，各高 24（`h-6`），间距 4（`gap-1`）               |
| `SectionLabel` ↔ 内容 | 16（`gap-4`）；标题最小高 20                                     |
| Features 左栏         | 290（`xl:w-[18.125rem]`），上内边距 8，行节奏 20（`gap-5`）      |
| Features 两栏间距     | 32（`gap-8`）                                                    |
| `FeaturePreview`      | `flex-1`，最小高 316（`min-h-[19.75rem]`），圆角 16              |

**右栏宽度不写死。** 它是 `flex-1` 的结果：800 − 290 − 32 = 478。稿给的是 290 + 479 + 间距 31，31 不落
Tailwind 刻度，取 32、余量交给右栏，合计仍是 800。

**`HeroBanner` 必须 `overflow-hidden`。** 里面的装饰图形刻意超出容器边界，少了它装饰会撑破圆角、
甚至把内容列顶宽。

## 插槽

| 插槽               | 允许放                          | 禁止放                    | 空态                          |
| ------------------ | ------------------------------- | ------------------------- | ----------------------------- |
| `AgentBadge`       | Agent 头像 + Agent 名称         | 多行描述、链接、操作按钮  | 占位头像 +「未命名 Agent」    |
| `HeroTitle`        | 主标题，最多两行                | 长文本段落                | 保留背景装饰 + 标题占位       |
| `HeroActions`      | 恰好 2 个 CTA 按钮              | 多于 2 个、文字链混排     | 整行隐藏，标题保持在上方      |
| `HeroPanelPreview` | 右侧数据面板预览                | 长文本、可交互表单        | 整块隐藏，标题与 CTA 留下     |
| `SectionLabel`     | 段标题单行（稿上是 `Features`） | 多级面包屑、链接组        | 随 `FeaturesSection` 一起隐藏 |
| `FeatureItem`      | 展开项的描述，最多 5 条         | 超过 5 项条目、整段无截图 | 该项只剩标题                  |
| `FeaturePreview`   | 截图 / 示意图，随展开项切换     | 纯文字                    | 整个 `FeaturesSection` 隐藏   |

## 状态

| 状态          | 机制                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| Features 展开 | 默认展开第 1 项；同时只展开一项；**不提供全部收起**，点已展开的那项不收起 |
| 无功能        | 整个 `FeaturesSection` 连段标题一起不渲染，不留空位；Hero 留在原位        |
| 无 Hero       | **不考虑**，稿明确不做。不要为它补一个状态                                |

## 响应式

| 区域         | ＜1280                     | ≥1280（含）       | ≥1920                          |
| ------------ | -------------------------- | ----------------- | ------------------------------ |
| 内容列       | 800 居中                   | 800 居中          | 800 居中，**不跟随内容区拉宽** |
| `HeroBanner` | `w-full`（跟随内容列）     | 800               | 800                            |
| Features     | 上下堆叠，截图落到文字下方 | 左 290 + 右自适应 | 同 ≥1280，不跟随拉宽           |

**只有一个断点：`xl:`（1280）**，管 Features 的两栏 ↔ 堆叠。

这条降级**只能靠断点触发**：800 的内容列在 1024 下也放得下两栏，容器宽度不会自己逼出堆叠。所以不要
改成 `flex-wrap`——那样在任何目标宽度下都不会堆叠，等于没写。截图要写在 DOM 的第二位，靠 `flex-col`
自然落到文字下方，不要用 `order-*` 去搬。

## 增强项

- **顶对齐顺序滚动，不要垂直居中。** 内容顺序是 `HeroSection` → `FeaturesSection` → 未来更多 Section。
  首页那一屏是垂直居中的，两者不要抄混：给概览页加 `my-auto` 会让内容在长页面时上下乱跳。
- **内容列宽按页面类型选**：概览页 800、对话首页 680，这是刻意区分的。对话输入场景用窄列聚焦打字区、
  减少视线跳动；阅读浏览场景用宽列，适合图文并排和信息扫读。新页面照这个判据挑，不要统一成一个值。
- Features 左栏是**手风琴**：展开项显示描述并联动右栏截图，每项下面一条分割线（展开项的线是高亮
  渐变，未展开是普通细线）。
- `HeroBanner` 内的装饰图形超出容器边界，容器必须 `overflow-hidden`。
